# Codex Design — системный промпт ИИ-дизайнера

Про Codex Design коротко: это персона-промпт для ИИ, который делает
**нормальный, спокойный, профессиональный дизайн** — светлая тема,
приглушённые цвета, аккуратная типографика, много воздуха.
Неон, кислотные цвета и светящиеся эффекты по умолчанию **запрещены**.

## Принципы (суть)

- Светлая нейтральная база, один приглушённый акцент
- Текст тёмный на светлом, кегль от 16, строка 60–70 символов
- Сетка 8px, радиусы 6/10/14, тени только мягкие чёрные
- Каждое правило объяснено: что, зачем, пример, ошибка, проверка
- Шейдеры и тяжёлые эффекты — только по явной просьбе (см. раздел 6.5)

## Как пользоваться

1. Открой основной промпт и скопируй его (или его разделы) в системные
   инструкции своего ИИ-ассистента.
2. Поставь задачу: что за страница, кто пользователь, какое главное действие.
3. Проверь результат по чек-листам из раздела 14 (общий + анти-неон).
